# Web_Page_Design
This project is a modern and responsive webpage design built using HTML, CSS, and JavaScript. The webpage includes a navigation bar, a search bar, a content area with a login form, and several social media links. The design is fully responsive, with media queries to adjust the layout for various screen sizes.

## Features
Navigation Bar: A horizontal navigation bar with links to different sections of the webpage.
Search Functionality: A search bar that allows users to input and search text.
Responsive Design: The webpage is fully responsive and adapts to different screen sizes, including mobile, tablet, and desktop views.
Login Form: A login form where users can enter their email and password.
Social Media Links: Icons linking to various social media platforms.
Animations: Hover effects and button animations enhance the user experience.
